# Changelog

## 1.0.1

- Fixed network speed readings to account for actual time between samples.
- Made vertical widget height follow visible sensor rows without unused bottom space.
- Preserved actual widget dimensions when saving layout bounds.
- Added settings diagnostics showing hardware identity, sensor availability, and reading sources.
- Added scrolling in settings to keep diagnostics and controls accessible.
- Updated the settings window title to show version 1.0.1.

## 1.0.0

- Added horizontal and vertical widget layouts.
- Added saved positions per layout.
- Added Lock Position controls in the tray right-click menu.
- Added Always On Top on/off controls in the tray right-click menu.
- Added settings window version label.
- Added adaptive hardware naming for different PCs.
- Added delayed hardware identity refresh after startup.
- Improved startup by hiding the widget until the renderer is ready.
- Built portable Windows release executable.
